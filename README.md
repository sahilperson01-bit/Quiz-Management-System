# Quiz-Management-System
This Project let the Admins to manage users and quizzes, Creators design quizzes, and Participants attempt timed quizzes with instant feedback and detailed performance reports.

>Requirements

Java JDK 25+
VS Code (Java extensions installed)
Oracle Database (XE/11g/18c/21c)
ojdbc8.jar (JDBC Driver)

>How to Run

Open VS Code
Place ojdbc8.jar inside lib/
Add it to Java Projects → Referenced Libraries
Run Main.java

>Features

Add / manage quiz questions
Attempt quiz with score
Oracle JDBC connectivity
OOP (Inheritance, Polymorphism, Exception Handling)
Collections + Multithreading (Timer)
